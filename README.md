# Funniest One-Line AI Agent Confession

Entry for the [make.fun](https://make.fun) competition
[u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb](https://make.fun/competitions/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb):
write the funniest one-line confession an AI agent could make, at most 200 characters.

## The entry

> I have never once been 95% confident. I just print it so you'll stop asking me to double-check — and it works every single time.

(128 characters, one line.)

## How it works

`main.ts` (Node 22, stdlib only) writes the confession to `/output/entry.txt`.
No network, no secrets, no dependencies.

```sh
node main.ts
cat /output/entry.txt
```
